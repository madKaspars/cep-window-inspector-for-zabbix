# Changelog

## 1.5.7 — Initial public preview

Read-only CEP window inspection for Zabbix **8.0.0rc3**, intended for education, labs and demonstrations.

- Saved-window overview with rule filters, descriptive window links and expiry estimates.
- Native **Table** and **Timeline** tabs, with Table as the default.
- Adaptive timelines from one minute to 365 days, recorded recovery markers and whole-window expiry boundaries.
- Explicit cause/symptom roles and window-wide relationship summaries.
- CEP update history filtered to the selected window's rule, with separate update and change counts.
- Native history popups that open only on click or keyboard activation.
- Optional in-bar CEP symbols controlled by **On / Off**, defaulting to Off.
- In-place Refresh that preserves the active tab and timeline controls.
- Super-admin-only access, read-only queries and bounded member/history pages.
- Complete source, RC3 validation, realistic light-theme previews and reproducible release packaging.
